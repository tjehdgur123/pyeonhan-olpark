# 편한길 올팍

휠체어·유아차를 이용하거나 오래 걷기 힘든 관람객이 올림픽공원 공연장(KSPO DOME, 티켓링크 라이브 아레나, 올림픽홀, 우리금융아트홀, K-아트홀 등)에 갈 때 필요한 정보를 한 화면에 모은 웹서비스입니다.

2026년도 한국체육산업개발(주) 공공데이터 활용 경진대회 응모작.

## 무엇을 알려 주나요

- **계단 없는 길 안내**: OpenStreetMap 보행로에서 계단을 뺀 길로 출구→공연장 최단 경로를 미리 계산해 지도에 그립니다.
- **엘리베이터 있는 출구**: 공원 공식 안내 출구와 실제 지상 엘리베이터 출구가 다른 경우를 경고합니다 (예: 몽촌토성역 공식 안내 1번 출구 / 엘리베이터는 4번 출구).
- **엘리베이터 실시간 가동 여부**: 5·8호선 주변 역 엘리베이터가 멈춰 있으면 알려 줍니다. 역 전화번호와 안전발판 보유 여부도 함께 보여 줍니다.
- **주차장 만차 예측**: 한국체육산업개발 실시간 주차현황을 Worker가 10분마다 기록해(Cloudflare 크론·KV) 최근 3시간 추세, '지금 속도라면 ○시 ○분쯤 거의 참', 지난주 같은 시각 비교를 보여 주고, 주차장 혼잡도 기록 263건으로 도착 권장 시각(정오 전, 늦어도 오후 1시)을 알려 줍니다.
- **저상버스 실시간**: 서울시 정류소정보·버스도착정보(교통약자용) API로 공연장 가까운 정류장의 저상버스 도착을 보여 줍니다(공연 후 탭).
- **자동차**: 공연장별 가장 가까운 주차장, 만차 기록, 실시간 주차 대수, 장애인 할인, 휠체어 진입로.
- **휠체어 무료 대여**: 가까운 안내센터와 운영시간. 공연이 19시 이후에 끝나면 반납 문제를 미리 경고합니다.
- **공연 뒤 혼잡**: 2025년 주차장 입출차 약 240만 건 중 대형 공연일 77일을 분석했어요. 종료 20~40분 뒤가 가장 붐비고(평소의 약 10배), 70분 뒤 절반, 90분 뒤 3분의 1로 줄어요. 이 흐름을 선택한 공연의 실제 시각에 맞춘 그래프로 보여 주고, 권장 출발 시각(종료 70분 뒤)과 '끝나기 직전에 먼저 나서기'라는 대안을 알려 줍니다. 출차의 36%는 동2문, 32%는 북2문, 26%는 남2문으로 나가요.
- **한눈에 보는 화면**: 가는 길은 노선도 한 줄 요약(출발역 → 환승역 → 엘리베이터 출구 → 공연장)과 한 줄 카드(엘리베이터 상태 칩: 정상·멈춤·정보 없음)로 보여 주고, 자세한 설명은 눌렀을 때만 펼칩니다. 공연 후 탭도 나설 시각·작은 혼잡 그래프·막차 한 줄로 정리했습니다.
- **지도로 따라가기**: 엘리베이터 출구에서 공연장까지 지도에 경로와 내 위치(GPS)를 띄우고, "왼쪽 · 70m"처럼 다음 안내 하나만 크게 보여 줍니다. 꺾이는 곳에 가까워지면 자동으로 다음 안내로 넘어가고, 음성으로도 들을 수 있습니다.
- **집 근처 출발역부터**: 출발역을 고르면 수도권 전철 노선(OpenStreetMap)으로 환승이 적은 길을 앱 안에서 계산해, 출발역·환승역 엘리베이터 실시간 상태(서울교통공사 1~8호선 전체 역), 타는 방면, 지하철 탑승 권장 시각, 다른 경로를 보여 줍니다. 길찾기는 카카오맵·네이버 지도·구글 지도 중 골라 열 수 있고, 저장한 출발역이 출발지로, 도착역 엘리베이터 출구가 목적지로 미리 들어갑니다(출발역이 없으면 현재 위치에서 출발).
- **막차 확인**: 서울교통공사 역별 막차 시간표로 공연장 근처 4개 역·노선의 막차와 '공연장에서 나설 시각'(걷는 시간 + 엘리베이터 여유 10분)을 보여 주고, 혼잡을 피해 기다리면 막차를 놓치는 경우 미리 알려 줍니다. 출발역을 정하면 국토교통부(TAGO) 역별 시간표로 갈아타는 역마다 막차를 거꾸로 계산해 '수원역 23:55 도착 막차 · 21:58까지 공연장에서 나서기'처럼 집(출발역) 도착 기준으로 알려 줍니다(갈아타기 10분, 공연장→승강장 걷는 시간+10분).
- **일행에게 보내기**: 고른 공연·이동 방법·만날 출구와 시각을 링크 하나로 보냅니다. 링크를 열면 같은 안내가 바로 열립니다.
- **앱처럼 설치 + 오프라인**: 홈 화면에 설치할 수 있고(PWA), 길 안내·지도·마지막으로 불러온 공연 일정은 통신이 끊겨도 열립니다.
- **장애인콜택시 안내**: 돌아갈 때 서울 장애인콜택시(1588-4388) 이용 팁과 동승 인원, 타는 곳 설명 방법을 알려 줍니다.
- **현장 제보**: 지도에서 위치를 골라 '턱·계단', '경사', '길 막힘', '엘리베이터 멈춤', '장애인 화장실 못 씀', '다니기 좋음'을 알릴 수 있어요. 다른 이용자가 '저도 봤어요/지금은 아니에요'로 확인하고, 30일 뒤 사라집니다. 목록은 최신순·추천순으로 볼 수 있고, '지금은 아니에요'가 더 많은 제보는 맨 아래로 내려갑니다. 이름·연락처는 받지 않고 글 속 전화번호·이메일·링크는 지우며, IP는 저장하지 않아요(Cloudflare Worker + KV, `worker/worker.js`). 경로 근처 제보는 '가는 길'에도 알려 줍니다.
- **공연 시간 추정**: 공식 소요시간이 없으면 공연정보 API(공연 2,502건)에서 같은 출연자의 지난 공연이나 공연장의 보통 소요시간으로 끝나는 시각을 추정합니다.

- **말로 하는 지도**: 계단 없는 경로를 '오른쪽으로 꺾어 북쪽으로 약 120미터, 왼쪽에 만남의광장' 같은 문장으로 바꿔 화면과 음성으로 안내합니다. 지도를 볼 수 없는 사람도 길을 알 수 있습니다.
- **다국어 (한국어·English·日本語·中文)**: 머리 오른쪽 언어 고르기로 바꿉니다. 화면을 그린 뒤 문장 틀 사전(`i18n-dict.js`, 원본 `tools/dict_src.py`)으로 바꾸고, 공연장·역·노선 이름은 이름표와 로마자 표기로 바꿉니다. 음성 안내도 고른 언어의 목소리로 읽고, 출발역은 로마자(예: Suwon)로도 입력할 수 있어요. 공연 제목은 원문 그대로 둡니다.
- **음성 안내**: 가는 길과 공연 후 안내를 단계별로 소리로 읽어 줍니다(브라우저 내장 음성, 천천히/보통 속도). 기기에 있는 한국어 목소리 중 자연스러운 음성(신경망·향상된 음질)을 먼저 고르고 '목소리'에서 바꿀 수 있으며, 시각은 '밤 11시 27분'처럼, 전화번호는 한 자리씩 읽도록 소리용 문장을 따로 다듬었습니다. 시각·인지에 어려움이 있거나 화면을 계속 보기 힘든 이동 중에도 쓸 수 있습니다.

## 구조

- 정적 웹사이트(HTML/CSS/JS, 빌드 없음) → GitHub Pages로 무료 운영
- 화면: KRDS(정부 디지털 서비스 디자인 시스템)의 색·글꼴·간격·모서리 규칙을 `krds.css`에 적용. 글꼴은 Pretendard GOV(SIL OFL 1.1)를 `fonts/`에 함께 둡니다. 정부 상징·명칭은 쓰지 않습니다.
- 주차·공연 정보: 한국체육산업개발 공개 API와 공식 페이지를 브라우저에서 직접 호출 (CORS 허용)
- 엘리베이터 실시간: `worker/worker.js` (Cloudflare Worker)가 공공데이터포털 인증키를 숨긴 채 중계. 주소를 `config.js`의 `LIVE_API`에 넣으면 켜집니다. 연결 전에는 저장된 스냅샷을 보여 줍니다.

## 한계와 추가 개방 제안

공원 안 경사로·턱·장애인 화장실·기저귀교환대 위치는 공개 데이터가 없어 걷는 시간을 직선거리로 추정합니다. 이런 데이터가 개방되면 실제 무장애 경로 안내가 가능합니다.
