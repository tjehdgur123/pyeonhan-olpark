# 편한길 올팍

휠체어·유아차를 이용하거나 오래 걷기 힘든 관람객이 올림픽공원 공연장(KSPO DOME, 티켓링크 라이브 아레나, 올림픽홀, 우리금융아트홀, K-아트홀 등)에 갈 때 필요한 정보를 한 화면에 모은 웹서비스입니다.

2026년도 한국체육산업개발(주) 공공데이터 활용 경진대회 응모작.

## 무엇을 알려 주나요

- **계단 없는 길 안내**: OpenStreetMap 보행로에서 계단을 뺀 길로 출구→공연장 최단 경로를 미리 계산해 지도에 그립니다.
- **엘리베이터 있는 출구**: 공원 공식 안내 출구와 실제 지상 엘리베이터 출구가 다른 경우를 경고합니다 (예: 몽촌토성역 공식 안내 1번 출구 / 엘리베이터는 4번 출구).
- **엘리베이터 실시간 가동 여부**: 5·8호선 주변 역 엘리베이터가 멈춰 있으면 알려 줍니다. 역 전화번호와 안전발판 보유 여부도 함께 보여 줍니다.
- **자동차**: 공연장별 가장 가까운 주차장, 만차 기록, 실시간 주차 대수, 장애인 할인, 휠체어 진입로.
- **휠체어 무료 대여**: 가까운 안내센터와 운영시간. 공연이 19시 이후에 끝나면 반납 문제를 미리 경고합니다.
- **공연 뒤 혼잡**: 2024년 7월 입출차 21만 건 분석으로, 공연 종료 후 40~50분은 출차가 평일의 3~5배라는 점을 선택한 공연의 실제 시각에 맞춘 그래프로 보여 주고 권장 출발 시각을 알려 줍니다.

## 사용한 공공데이터

| 기관 | 데이터 | 쓰임 |
|---|---|---|

분석 과정에서 만든 중간 자료는 `analysis/` 폴더에 있습니다.

## 구조

- 정적 웹사이트(HTML/CSS/JS, 빌드 없음) → GitHub Pages로 무료 운영
- 주차·공연 정보: 한국체육산업개발 공개 API와 공식 페이지를 브라우저에서 직접 호출 (CORS 허용)
- 엘리베이터 실시간: `worker/worker.js` (Cloudflare Worker)가 공공데이터포털 인증키를 숨긴 채 중계. 주소를 `config.js`의 `LIVE_API`에 넣으면 켜집니다. 연결 전에는 저장된 스냅샷을 보여 줍니다.

## 한계와 추가 개방 제안

공원 안 경사로·턱·장애인 화장실·기저귀교환대 위치는 공개 데이터가 없어 걷는 시간을 직선거리로 추정합니다. 이런 데이터가 개방되면 실제 무장애 경로 안내가 가능합니다.
