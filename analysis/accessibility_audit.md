# 접근성 점검 결과 (2026-11-23)

## 도구
- Google Lighthouse 12 (접근성·권장사항·SEO)
- axe-core 4 (WCAG 2.0/2.1 A·AA + 권장 규칙)
- 점검 화면: 첫 화면, 가는 길, 공연 후, 지도, 공연 선택 시트 × 밝은/어두운 화면, 글자 크기 '아주 크게', 자동차 모드, '다른 역' 펼침

## 점검 전 발견한 문제와 조치
| 문제 | 영향 | 조치 |
|---|---|---|
| 9호선 노선 표시(흰 글자/금색 배경) 명도 대비 2.14:1 | 저시력 사용자가 노선명을 읽기 어려움 | 배경색 밝기를 계산해 대비 4.5:1 이상이 되는 글자색(흰색/검정)을 자동 선택 |
| 글자 크기·말하기 속도 버튼의 화면 글자와 스크린리더 이름 불일치 | 음성 명령(“글자 크기 누르기”)으로 조작 불가 | 화면에 보이는 문구를 그대로 접근 이름으로 사용 |
| 하단 탭바가 랜드마크 밖에 있음 | 스크린리더 랜드마크 이동 시 누락 | `<nav>` 랜드마크 안에 탭 목록 배치, 각 탭에 `aria-controls` 연결 |
| 본문 바로가기 없음 | 키보드 사용자가 상단 바를 매번 지나야 함 | ‘본문 바로가기’ 링크 추가 |

## 조치 후 결과
- Lighthouse 접근성 **100점**, SEO 100점, 권장사항 96점(점검 환경에서 외부 API에 접속하지 못해 생긴 콘솔 오류 때문)
- axe-core: 위 10개 화면 상태 모두 **위반 0건**
- 키보드만으로 이동 방법 선택 → 공연 선택 → 탭 이동 → 음성 안내까지 조작 가능

## 이미 갖춘 접근성 기능
- 글자 크기 3단계(16·20·24px), 화면 전체가 같은 비율로 커짐
- 모든 버튼 최소 44×44px 터치 영역
- 단계별 음성 안내, 지도 내용을 글·음성으로 제공(‘말로 하는 지도’)
- 움직임 줄이기 설정 시 경로 애니메이션 끔
- 밝은/어두운 화면 자동 대응
